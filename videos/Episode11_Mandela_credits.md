## 3D
Huit plans modélisés et rendus pour la vidéo avec Blender (EEVEE) :
- la porte de prison ;
- Robben Island ;
- la cellule à l'échelle (2,10 m × 2,40 m) ;
- le calendrier 1964-1990 ;
- le globe ;
- l'urne ;
- le drapeau ;
- le plan final.

Les décors sont des reconstitutions, signalées à l'écran. Le globe utilise les frontières Natural Earth / world-atlas (domaine public).
