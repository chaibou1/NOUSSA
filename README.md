# Student Project Portfolio

A Next.js application for showcasing student projects with photo uploads, descriptions, and contributor management.

## Features

- Project description editing
- Photo gallery with descriptions
- Contributor section with photos
- File upload functionality

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Usage

- Edit the project description in the textarea.
- Upload project photos with descriptions.
- Add contributors with their photos.

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
